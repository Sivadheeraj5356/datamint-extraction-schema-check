Extraction Schema Check

When an LLM pipeline extracts structured data at scale, small quality problems multiply: records that violate the schema, fields that drift type, extracted fields nobody declared (token waste), and HTML residue in clean text. Paste a JSON Schema and extracted records (one JSON per line); the check flags potential issues using heuristics - it is a screen, not a full extraction audit.
